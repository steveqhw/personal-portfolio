## Sintesi

Questa pagina e' un modello iniziale per documentare un progetto hardware.

## Obiettivo

Descrivi il problema tecnico o funzionale che il progetto deve risolvere.

## Architettura

Elenca i blocchi principali del sistema, per esempio alimentazione, microcontrollore, interfacce, sensori, attuatori o circuiti analogici.

## Scelte progettuali

Documenta le decisioni rilevanti: componenti scelti, vincoli di costo, disponibilita', consumo, ingombro, segnale, isolamento, protezioni o produzione.

## PCB

Riporta note sul layout, stack-up, dimensioni, vincoli meccanici, routing critico e gestione termica.

## Test

Descrivi le misure eseguite, gli strumenti usati e i risultati ottenuti.

## File e riferimenti

Aggiungi link a repository, documentazione, immagini, datasheet o file pubblicabili.
